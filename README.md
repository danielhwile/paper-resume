# paper-resume

A resume site styled as a sheet of paper with torn-paper tabs. Plain HTML, CSS and a little JS — no build step.

- Paper texture: inline SVG noise + layered shadows
- Torn edges: SVG `feTurbulence` + `feDisplacementMap` filter on the tab background only
- Accessible tabs (ARIA, arrow-key navigation) and a print stylesheet

Open `index.html` in a browser, or enable GitHub Pages to publish it.
